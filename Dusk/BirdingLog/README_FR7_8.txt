- Métadonnées du plugin mises à jour pour identifier clairement le fork Dusk-92.
- Le site du plugin pointe désormais vers le dépôt GitHub du fork.
- L'ancien fichier .plugincompendium utilisant l'identifiant LOTROInterface 1241 de la publication originale a été retiré du fork.
- Ajout d'un README.md avec installation, commandes, crédits, fonctionnement FR et limites connues.

Compatibilité des anciennes sauvegardes conservée.
